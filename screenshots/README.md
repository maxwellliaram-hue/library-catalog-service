# Atlas screenshots

Place the required screenshots for this assignment in this folder using these names:

- books.png
- genres.png

How to capture them:

1. Open MongoDB Atlas.
2. Go to your cluster and open the Collections view.
3. Click the `books` collection and capture a screenshot showing at least 15 documents.
4. Save it as `books.png`.
5. Repeat for the `genres` collection and save it as `genres.png`.

These screenshots are required for the course submission portal.
